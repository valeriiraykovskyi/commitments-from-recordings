# Video walkthrough — script (≤ 3 minutes)

Record the demo at https://commitments-from-recordings.vercel.app in a browser window about
1280 px wide, with the results column and the transcript side by side. Speak over the screen;
no slides. Times are targets.

**0:00–0:15 — The problem.** Start screen. "A recorded discussion goes in; what comes out is
not a summary but the list of what was actually agreed: tasks, owners, deadlines and open
questions, each with a quote you can play. Nothing is inferred: if it was not said, it is not
shown."

**0:15–1:15 — Normal input.** Click *Launch sync*. Point at the steps and their times; the
transcript appears after a second or two, the result usually in about fifteen. The model's
reasoning time varies a lot — a run can take forty or fifty seconds — so read the number on
screen rather than a rehearsed one, and if it is a slow one, say so: the delivery notes report
the tail and name it as the first thing to fix. Then, top to bottom:

- *Agreed*: three tasks. Analytics has an owner and "by Wednesday", flagged "date not stated in
  the recording". Release notes shows "Monday · corrected from Friday". App Store screenshots
  shows "No owner agreed" instead of a guessed name.
- Click the play button on "Let's say Monday instead" — the segment plays and the transcript line
  lights up.
- *Unresolved*: the Canada question, raised and never answered.
- Open *Not commitments*: the dark mode was only "maybe we could", so it is not agreed; the
  migration script was accepted and then cancelled, so it is excluded, with the quote.

**1:15–1:40 — One changed agreement.** Click *New recording*, then *Launch sync, one change*.
"Same conversation, one line changed: legal approved the import." The migration script now sits
under *Agreed* with its owner. "The samples go through the same pipeline as an upload; nothing is
prepared."

**1:40–2:05 — Clarify instead of guessing.** *Undecided talk*. The banner asks who the speakers
are, because nobody introduced themselves. Zero agreed tasks; two items "need confirmation"
because the only answers were "no promises" and "not sure".

**2:05–2:25 — Refusals.** *Too long*: refused in the browser flow before any paid call, $0.
*Spanish*: transcribed, recognised as Spanish, refused before the model is called.

**2:25–2:50 — Measurements.** Scroll to *Measurements* on any result: time in the browser and
per stage on the server, the cost of this operation by component, at the peak tariff, per
audio minute, and hosting separately. "These are measured on every run, at list prices."

**2:50–3:00 — Close.** "The eval runs every sample three times against hand-written expected
results: fifteen of fifteen on the current prompt. The repository has the test set, the eval
reports and the delivery notes."

Tips: run each sample once before recording so you know the timings; keep the cursor still while
talking; if a run takes longer than usual, keep talking about the transcript, it is already on
screen.
