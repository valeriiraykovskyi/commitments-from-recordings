# Demo — Help centre handover (for the video walkthrough)

Not part of the test set and not bundled with the app: this one is **uploaded** in the video,
to show that new input goes through the same pipeline as the samples. It is deliberately a
different conversation from T1 — different people, different work, different wording.

Two speakers: Dina (head of support) and Victor (technical writer). Both introduce themselves.
The recording never states today's date, so every deadline stays as spoken.

What should come out, written before the recording was made:

- **Agreed:** export the current articles — Victor — "Monday", corrected from "by Thursday" ·
  rewrite the billing guide — Victor — no deadline · warn the customers — **no owner** —
  "before the old links break"
- **Unresolved:** whether the old help centre stays online as a backup
- **Not a commitment:** a video for each article — only "we could", and it was put off
- **Cancelled:** the redirects — agreed, then taken off Victor's list

Checked before the video: the pipeline returns exactly this, with both speakers named and no
clarification. Three lines were reworded until recognition carried them, the same way T1 was:
"I'm Dina, I run the support team" came back as "Hi, Amdina. I'm on the support team"; "We could
record" flattened to "We can record", which would have removed the hedge; and the two-word turn
"Monday works." came back as "Lenny works."
